# 독서관리 프로그렘 제작

## 도서 정보를 등록, 조회, 수정, 삭제할 수 있는 웹 프로그렘 제작

## 구현 기능

- 도서 전체 조회 : 서버에 저장된 모든 도서 목록 출력
  -- 전체 도서 개수 화면에 표시, 도서 목록을 등록일 또는 제목순으로 정렬
- 도서 검색 : 도서 제목, 장르로 검색 (검색어가 제목에 포함된 도서만 출력, 도서가 없을 경우 안내 메시지 출력)
- 도서 등록 : 제목, 저자, 출판 연도, 간단한 설명 입력 (등록할 때 id를 자동으로 증가, 입력값이 비어 있으면 등록되지 않도록 검사)
- 도서 삭제 : 도서 ID를 이용하여 삭제 (삭제 전 사용자에게 CONFIRM()으로 확인받기)
- 도서 수정 : 등록된 도서 정보 수정 (모달창으로 구현)

## 개발 환경

- 백엔드 : Python FastAPI
- 데이터 저장 : Python 리스트와 딕셔너리
- 데이터 검증 : Pydantic BaseModel
- 프론트 엔드 : HTML, CSS, JavaScript
- 서버 통신 : Fetch API
- HTTP 메서드 : GET, POST, PUT, DELETE
